# Review Mobile

A self-study mobile roadmap covering **Android (Kotlin)** and **iOS (Swift / SwiftUI)** side by side. Each lesson has demos, exercises with auto-graded tests, and solutions.

| Platform | Repo | Open with |
|---|---|---|
| Android | [review-mobile-android](https://github.com/tuanmanh28/review-mobile-android) | Android Studio (JVM 21) |
| iOS | [review-mobile-ios](https://github.com/tuanmanh28/review-mobile-ios) | Xcode 16+ |

## Get the code

```bash
mkdir review-mobile && cd review-mobile
git clone https://github.com/tuanmanh28/review-mobile-android.git android
git clone https://github.com/tuanmanh28/review-mobile-ios.git ios
```

How to run, how to work through a lesson, and how to add a new lesson are covered in each repo's README.

## Conventions

- Lesson numbers **match on both sides**: Lesson 1 Android ↔ Lesson 1 iOS (same topic, written for each language).
- Each lesson is structured as: `demo` → `exercises` (fill in the `TODO`s) → tests → `solutions`.
- When a lesson is done, tag both repos with the same name, e.g. `lesson-01`.
